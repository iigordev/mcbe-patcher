# Minecraft Bedrock Patcher


> [!CAUTION]
> This is NOT a full Minecraft Bedrock port to Mac. This is only a tool to tweak the iPad/iPhone version of MCBE.
>
> Features like Xbox Accounts, Multiplayer, Servers, Realms, Marketplace, etc. won't work. (Will return Error Code: Drowned)
>
> You will still need to sideload the app every 7 days. (although patching is not neccesary)

Minecraft Bedrock Tweaker/Patcher is a tool to patch Minecraft Bedrock .ipa files to run on macOS.

## Requirements

- An Apple Account
- Sideloadly
- Apple Silicon Mac (M1 or newer)
- macOS version 15 or newer recommended
- Minecraft Bedrock IPA, you can find Minecraft Preview .ipa's [here](https://archive.org/details/NL-IPAA-02) (Otherwise just find an ipa website).

> [!NOTE]
> macOS version may depend more on Sideloadly's supported versions.

> [!WARNING]
> Using older versions than 1.19.10 will result the game to have touchscreen UI, and the KBM features to not work. This is because Mojang has implemented Keyboard & Mouse features on 1.19.10.


## Guide

After you've downloaded `mcbe_patcher.zip` from [releases](), open `start.sh`. 

- After the app opens, drag your Minecraft.ipa onto the dropbox.
- Click "Patch".
- You will get a new IPA in your downloads folder named "mcbe_tweaked_version.ipa".
- Open Sideloadly.
- Log into your Apple Account in Sideloadly.
- Make sure your Mac is selected as the "iDevice"
- Select the IPA, and press Start.
  
> [!IMPORTANT]
> You can press the settings icon next to the "Patch" button to change between Retina mode and no Retina mode.

- After it has installed, open the game through the Launchpad.
- You might need to unlock it through Privacy & Security in settings, after that you're good to go!
